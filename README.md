Entrants send exactly one word, the first that comes to mind. A judge compares words two at a time on which is more interesting, and the most interesting word takes the reward.

This entry's word is **psithurism** — the sound of wind whispering through trees. It was picked against the judge's own criteria: surprising (an obscure word for a sound everyone knows but almost no one can name), vivid (a clear auditory image in ten letters), and witty (the word itself whispers — "psith-" sounds like the rustling it describes).

## Run it

```sh
python3 main.py
```

This writes exactly one word, `psithurism`, to `/output/entry.txt` — no trailing newline, so the file is exactly 10 bytes.
